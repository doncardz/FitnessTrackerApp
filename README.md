# 💪 FitnessTrackerApp

A simple offline fitness tracker desktop application built with Java and JFrame. This app is designed to help people monitor their health and fitness journey — one day at a time.

---

## 📋 Features

### ⚖️ Weight Tracker
- Log your daily weight (kg)
- View your progress through a graph
- Track if you're hitting your weight goals

### 💧 Water Tracker
- Log your daily water intake
- Set a daily water goal (e.g., 8 glasses)
- See if you're hitting your hydration goal for the day

### ✅ Daily Checker
- Set daily fitness plans and goals
- Check off what you've accomplished
- View your progress through a calendar

---

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| Java | Main programming language |
| JFrame (Java Swing) | Desktop UI |
| SQLite | Local offline database |
| JFreeChart | Weight progress graph |

---

## 🚀 Getting Started

### Requirements
- JDK 17 or higher
- IntelliJ IDEA (Community Edition)

### How to Run
1. Clone this repository
```
git clone https://github.com/yourusername/FitnessTrackerApp.git
```
2. Open the project in IntelliJ IDEA
3. Run `Main.java`
